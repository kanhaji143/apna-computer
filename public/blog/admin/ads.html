Before you start

Paste the full ad snippet (e.g. the <ins class="adsbygoogle"> block) into the box for each slot. A slot only renders on the site when its toggle is ON and the code box is not empty — otherwise it stays hidden, so no broken gaps appear. Google AdSense requires a Privacy Policy, real content and site verification before ads go live; you already have the policy page.
